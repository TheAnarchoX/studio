# Books, part 2: the composer — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Studio sets a book as real pages with Typst, shows them in a Compose view and a pages pane while writing,
exports a print-on-demand interior PDF whose generated pages (contents, notes, bibliography, index) are right, runs
print checks, checks spelling in several languages at once, and makes the writing window's tools findable.

**Architecture:** Python turns each piece's document (`manuscript.parse`) and the book's resolved design into one
Typst source (`typeset.py`, plus a Typst template file with the page rules and generated pages). `compose.py` is the
service the routes (and later the MCP tools) call: it stages the source, images and cut font instances in a cache
folder, compiles with a per-book `typst.Compiler`, and returns pages as SVG addressed by content hash, a page map for
the text, the PDF, and PNG pages for the checks. The browser shows pages as `<img>`; it never runs Typst. Spelling is
Hunspell in WebAssembly in a Web Worker, as ProseMirror decorations.

**Tech Stack:** Python 3.11+, `typst==0.15.2` (new), fontTools (instancer), Pillow; unittest; plain JS/CSS;
Hunspell via `hunspell-asm@4.0.2` vendored with esbuild at development time only.

**Spec:** `docs/superpowers/specs/2026-11-13-books-part-2-design.md`. Part 1's spec and plan
(`2026-11-12-books-design.md`, `2026-11-12-books-part-1.md`) describe the code this builds on.

## Review focus

1. **Typst syntax in the author's text** (`#let`, `$x$`, `[`, `]`, `<label>`, `@key`, `\`, `"`, `//`, `/*`, `*`, `_`,
   `=` at a line start, a raw `#import "@preview/x:1.0.0"`): it prints literally and never runs or downloads anything.
   Pinned in Task 4 (`test_user_text_is_never_code`).
2. **Broken material:** a missing or unreadable piece file, an empty piece, a piece without a title, a book with no
   pieces, a missing image, an image path pointing outside `images/` (`../../x.png`), a linked poem that's gone: the
   book still sets (missing image → a framed note in its place; unreadable piece → the same plain error the export
   gives), and nothing outside the book is read. Pinned in Tasks 4 and 6 (`test_broken_material_still_sets`).
3. **Saves during a compile, and several viewers:** a save while compiling gives the next poll a fresh compile; two
   requests at once compile once and both get the result; a page hash requested after a recompile that dropped it is
   a 404 the viewer answers by refetching the page list. Pinned in Task 6 (`test_concurrent_requests_compile_once`).
4. **Fonts that can't be used as asked:** a look whose text font is a system font, a family without italic or bold,
   a font that may not be embedded (`fsType` restricted), characters the font lacks (Greek, Cyrillic, ₂): the book sets
   (Literata stands in for a non-embeddable family), and the checks name each problem. Pinned in Tasks 2 and 7.
5. **Dutch specifics:** particles in names ("van Dijk" cited, sorted under D), `'s avonds`, „…” quotes, accents in
   index terms (Één sorted with E), hyphenation of long compounds, month names. Pinned in Tasks 1, 4 and 5.

### Task 2: Font instances for typesetting

**Files:**
- Create: `studio/typeset_fonts.py`, `tests/test_typeset_fonts.py`
- Modify: `pyproject.toml` (dependency `typst==0.15.2`)

**Interfaces:**
- Consumes: `fonts.registry().get(name) -> Family | None` and `Family.file_for(italic, weight) -> FontFile`
  (`path`, `axes` {tag: (min, default, max)}, `weight`, `italic`, `embeddable`, `index`, `collection`).
- Produces: `typeset_fonts.FALLBACK = "Literata"` (bundled, OFL).
- Produces: `typeset_fonts.Face = namedtuple("Face", "role family internal style weight path problems")`.
- Produces: `typeset_fonts.prepare(roles: dict[str, dict], cache: Path) -> dict` — `roles` maps a role (`"text"`,
  `"heading"`) to `{"family": str, "weight": int, "opsz": float}`; returns `{"folder": Path, "names": {role:
  internal family name}, "faces": [Face], "problems": [str]}`. For each role it writes four faces — regular (the
  role's weight), bold (700, or the nearest the family has), italic and bold italic — renamed to the internal family
  `f"{family} {Role}"` (e.g. `Literata Text`), with name IDs 1, 2, 4, 6, 16, 17 rewritten, `OS/2.usWeightClass`,
  `fsSelection` (italic, bold, regular bits) and `head.macStyle` set. Variable files are instanced with
  `fontTools.varLib.instancer.instantiateVariableFont(font, loc, updateFontNames=False)` at `wght` and, when the file
  has it, `opsz` clamped to its range; static files are only renamed. A family without italic uses its roman for the
  italic faces and adds a problem ("<family> has no italic: italics are set upright"). A family that isn't found, or
  whose files may not be embedded, is replaced by `FALLBACK` with a problem naming it. Cut faces are cached as
  `cache/typeset-fonts/<sha1 of (source path, mtime, size, index, loc, internal name)>.ttf`; `folder` is
  `cache/typeset-fonts/sets/<sha1 of the face file names>/` holding hard links (copies where linking fails) to exactly
  this design's faces, so Typst sees nothing else.
- Produces: `typeset_fonts.covers(faces: list[Face], text: str) -> dict[str, str]` — characters of `text` (letters,
  digits, punctuation; not whitespace or control characters) missing from the role's regular face's cmap → `{char:
  role}`; and `typeset_fonts.has_smallcaps(face: Face) -> bool` (GSUB lists `smcp`).

### Task 4: Typesetting a piece

**Files:**
- Create: `studio/typeset.py`, `tests/test_typeset.py`

**Interfaces:**
- Consumes: `manuscript` documents (node and mark shapes as in `manuscript.SCHEMA`; `cite.attrs.items`, `idx.term`
  with `a > b` subentries, `lang.lang`, `image.src/alt/width`, `poem.src`), `citations.cite_text`.
- Produces: `typeset.lit(s: str) -> str` — a Typst string literal: `"` + `s` with `\` → `\\`, `"` → `\"`, newline
  → `\n`, tab → `\t`, other C0 controls dropped + `"`. All user text enters content as `#lit(...)` inside markup or
  as a literal argument in code.
- Produces: `typeset.Context` (a dataclass) with: `design` (resolved), `lang`, `sources`, `notes` (`off`, `footnotes`,
  `endnotes`, `both`), `numbering` (`chapter`/`book`), `images: dict[str, str]` (manuscript `src` → staged path
  relative to the compile root, or absent), `linked: callable(src) -> dict` (`Books.linked_poem`), and collectors
  filled while setting: `endnotes: list[dict]` (`{"piece": i, "n": int, "body": str}`; `body` is Typst content
  source), `terms: dict[tuple[str, str], str]` ((term, sub) → key `t<k>`), `first_lines: list[(text, i)]`,
  `cited: list[str]`, `missing_images: list[(i, src)]`, `chars: set[str]` (every printed character, for the font
  check), `note_counter: int`.
- Produces: `typeset.piece(i: int, entry: dict, doc: dict, ctx: Context) -> str` — the Typst source of piece `i`
  (its index in the book's `contents`). It calls template functions defined in Task 5 (`#piece-start`, `#piece-title`,
  `#section`, `#scene-break`, `#epigraph`, `#poem`, `#image-block`, `#missing-image`, `#note-ref`, `#piece-end`) and
  places markers:
  - `#metadata((p: i, b: k))<blk>` before top-level block `k` (index in `doc.content`), and
    `#metadata((p: i, b: k))<blkend>` after each paragraph's last inline node (for the widow and orphan check);
  - `#metadata((t: key))<idx>` right after the marked text of every `idx` mark;
  - `<noteref-i-n>`/`<note-i-n>` labels for endnotes (the reference links to the note, the note back to it).
  Mapping: em → `#emph[...]`, strong → `#strong[...]`, smallcaps → `#smallcaps[...]`, lang → `#text(lang: "xx")[...]`
  (lang validated with `config.LANGUAGE_TAG`, else ignored), comment → its text only, hard_break → `#linebreak()`,
  cite → `#lit(cite_text(...))`, note → per `ctx.notes`: footnotes → `#footnote[...]`; endnotes → `#note-ref(i, n)`
  and the body collected; both → `#footnote[...]` and collected; off → nothing printed. Note numbers come from
  `ctx.note_counter` (reset per piece when `numbering == "chapter"`); footnote numbering in Typst is reset per piece by
  `#piece-start` when numbering is `chapter`.
  Blocks: title → `#piece-title(i)[...]` (the first `title` only); heading level 2/3 → `#section(2|3)[...]`; paragraph
  → its inline content and a blank line (in a piece whose `form` is `poem`, paragraphs are stanzas, see poem);
  blockquote → `#quote(block: true)[...]`; scene_break → `#scene-break()`; page_break → `#pagebreak(weak: true)`;
  epigraph → `#epigraph((para, …), attribution)`; poem (and a `poem`-form piece's body) → `#poem(((line, …), …))` —
  stanzas of lines, each line content (hard breaks split lines); a linked poem uses `ctx.linked(src)["lines"]` (blank
  lines split stanzas) or prints the part 1 text "This poem is no longer in your Poems library."; poem pieces add
  their first line to `first_lines`; image → `#image-block(path, width, caption)` with `width` as a ratio of the
  measure (`"60%"` → `60%`; anything else → `100%`), or `#missing-image(caption)` when `src` isn't in `ctx.images`
  (recorded in `missing_images`).
