# Books, part 3: the research board — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One research board per book and a shared board — notes, images, web clips, quotes, sources and links to
pieces on a canvas and in a list, with frames, tags, search, moving and linking between boards — and quotes dragged
from the board into the text with their citation.

**Architecture:** Plain files: one Markdown file with a front matter per item in `research/` (a book's) or
`Research/` (shared), positions and frames in `board.json`. `studio/frontmatter.py` reads and writes the files,
`studio/research.py` is the store, `studio/clip.py` fetches and reads web pages (Chrome photographs a script-free
copy), `studio/routes_research.py` the API. In the browser: `board-core.js` (pure helpers and the data layer),
`board-canvas.js`, `board.js` (the page: sidebar, toolbar, list, item panel), `board-rail.js` (the writing window's
panel and the drop into the text).

**Tech Stack:** Python 3.11+ stdlib (`html.parser`, `http.client`, `ssl`, `ipaddress`, `zlib`), markdown-it-py
(already a dependency) for showing Markdown, Pillow (already) for JPEG and thumbnails, headless Chrome via
`studio/shoot.py`; plain classic-script JS and CSS, ProseMirror (vendored) for the drop; unittest; node for JS helpers.

**Spec:** `docs/superpowers/specs/2026-11-13-books-part-3-research-board-design.md` — read it first; this plan
argues from it and doesn't repeat its rulings.

## Review focus

1. **A board file edited by hand or by another program** — CRLF, a BOM, YAML typed by a person (unquoted strings,
   block lists, comments), a file with no front matter, a file that isn't UTF-8, a `board.json` that is broken: the
   board still opens, nothing is rewritten on read, an unreadable item shows as such. Pinned in Task 1
   (`test_hand_written_files`, `test_broken_board_json_reads_empty_and_is_kept`).
2. **Two windows (or Claude) on one board** — moving different cards in two windows keeps both moves; editing one
   note in two windows gives the second a 409 with the current text. Pinned in Tasks 2 and 4
   (`test_layout_merges_two_writers`, `test_stale_update_409_over_http`).
3. **Hostile or odd web pages** — a redirect to `127.0.0.1:<port>`, a page in Windows-1252 with a `<meta charset>`,
   gzip, a 30 MB page, a page whose `<title>` is empty, scripts in SVG and `onload` attributes: refused or cleaned,
   never run, never a crash. Pinned in Task 3 (`test_redirect_to_loopback_refused`, `test_meta_charset`,
   `test_safe_page_strips_everything_active`, `test_too_large`).
4. **Dropping a quote into Dutch prose** — the book's „…” marks, a quote that already holds quote marks, a quote with
   *italics*, a drop inside a note, a drop while autosave is running: the text lands once, where dropped, saved like
   typing. Pinned in Task 5 (`quoteParts` cases) and Task 9's browser check.
5. **Names with diacritics, reserved names and repeats** — `Één brief`, `CON`, two notes titled the same, an image
   named `photo.JPG` twice, a tag with spaces: valid unique ids and files. Pinned in Task 1 (`test_ids`).

### Task 1: Front matter and the research store core

**Files:**
- Create: `studio/frontmatter.py`, `studio/research.py`, `tests/test_research.py`

**Interfaces:**
- Produces `frontmatter.parse(text: str) -> tuple[dict, str, bool]` (fields, body, had front matter) and
  `frontmatter.dump(fields: dict, body: str) -> str`.
  - Reading: a BOM and CR are dropped; front matter is a first line `---`, then `key: value` lines, then `---`. A value
    that parses as JSON is that JSON; otherwise a plain string (surrounding single or double quotes removed, `''` →
    `'`); an empty value followed by `  - item` lines is a list (items read the same way); `#` lines are skipped.
    No closing `---` → no front matter (the whole text is the body).
  - Writing: `---\n`, one `key: <json.dumps(value, ensure_ascii=False)>` per key — order `type, title, tags, source,
    locator, from, url, site, author, published, fetched, shot, file, book, board, item, csl, created`, then any other
    keys in their order — then `---\n`, then the body with exactly one final newline (an empty body writes nothing).
- Produces in `research.py`: `KINDS = ("note", "quote", "source", "clip", "image", "piece", "link")`;
  `CARD_W = {"note": 240, "quote": 280, "source": 260, "clip": 300, "image": 240, "piece": 260, "link": 260}`;
  `CARD_H = {"note": 160, "quote": 170, "source": 120, "clip": 280, "image": 200, "piece": 150, "link": 160}` (estimates
  for placing); `FILE_TYPES = (".png", ".jpg", ".jpeg", ".gif", ".webp", ".pdf")`; `SHARED_DIR = "Research"`;
  `SHARED_URL = "_shared"`; `EXCERPT = 280`;
  `class ResearchError(StoreError)` — `ResearchError(message, code=400, details=None)` with `.code`, `.details`;
  `class Research(library: Path | None = None)` with `.library`, `.books` (a `books.Books(library / "Books")`) and
  - `board_dir(board) -> Path` — `None` → `<library>/Research`; a book id → `Books.dir(book) / "research"` (404
    `ResearchError` for an unknown book, message from `BooksError`);
  - `boards() -> list[dict]` — the shared board first, then every book in shelf order: `{"board", "title", "items"}`;
  - `read(board) -> dict` — `{"board", "title", "items", "frames", "tags": {tag: n}, "kinds": {kind: n}, "stamp"}`;
    item summaries as in the spec's "An item summary"; `pos.placed` false for items without a `board.json` entry,
    placed in a column 80 units right of everything placed (or at x 0), from the top of everything placed (or y 0),
    24 apart, in order of `created`;
  - `item(board, id) -> dict` — the summary plus `text` (the body), `html` (`markdown_it.MarkdownIt("commonmark",
    {"html": False, "linkify": False})` rendering of the body, links given `target="_blank" rel="noopener noreferrer"`),
    `mtime`, `extra` (front matter keys Studio doesn't know);
  - `add(board, fields: dict, at: dict | None = None, frame: str | None = None) -> dict` — `fields["type"]` one of
    `note, quote, source, piece, link` (clips and images have their own functions), `fields["text"]` the body; returns
    `item()`;
  - `update(board, id, fields: dict, base_mtime=None, force=False) -> dict`;
  - `delete(board, ids: list[str]) -> list[str]` (trash paths);
  - `stamp(board, every=False) -> float`; `file(rel: str) -> Path`.
- Rules: ids per the spec (reuse `books._slug(title, kind)`, `-2`, `-3` for repeats compared case-insensitively,
  Windows-reserved stems get `-1` like `books`); the stem comes from `title`, else the first six words of the text,
  else the kind. `created` is `datetime.now().isoformat(timespec="seconds")`. `tags`: strings, whitespace squashed,
  at most 40 characters, no empty or duplicate (case-insensitive) tags. `update` accepts `title, text, tags, source,
  locator, csl, from` and, for `piece`, `book, file`; anything else → 400 `"<key> can't be changed here."`; changing
  `type` → 400. Stale rule exactly as `Books.save_piece` (`abs(mtime - base) > 1e-6` → 409 with `{"current": item}`).
  A quote's `source` must match `manuscript.CITE_KEY` (or be empty); a `csl` must be an object whose `id` matches
  `CITE_KEY` and that has a `type`; a `source` added without a `csl.id` gets a key by `source_key(csl, taken)` — a
  Python port of `sourceKey` in `book-tools.js` (letters suffix `b`, `c` …) over the keys in reach of the board (Task 2's
  `citable`; in this task, the board's own items). Reads are cached per `(path, mtime_ns, size)` (cap 4096 like
  `books._COUNTS`). An unreadable item (not UTF-8) is listed with `"error"` and `type` `"note"`, is never written, and
  `update` on it is a 400. Delete moves `<id>.md` to `<board>/.trash/<YYYYmmddTHHMMSS> <id>.md` and each of its files
  (`shot`, `file`) to `.trash/<same stamp> <id> <file name>`, and drops its `board.json` entry. `board.json` that
  can't be read reads as empty and is left as it is until the next layout write; `layout` (Task 2) then writes a
  fresh one. `stamp` is the newest mtime of the board folder, its `*.md`, `board.json` and `files/` (not `.trash`);
  `every` covers every board. `file(rel)`: `rel` is `<_shared | book id>/<name>`, resolved inside that board's
  `files/`, suffix in `FILE_TYPES`, never a dot-name, never outside; else 404.

### Task 2: Layout, frames, links, moving, sources and search

**Files:**
- Modify: `studio/research.py`, `tests/test_research.py`

**Interfaces:**
- Consumes: Task 1.
- Produces on `Research`:
  - `layout(board, items: dict | None = None, frames: list | None = None, remove_frames: list | None = None) -> dict`
    (returns `read(board)`): `items` is `{id: {"x", "y", "w"?, "h"?, "z"?, "frame"?}}` merged into `board.json` by id
    under a module lock (ids of missing items are ignored); numbers finite, |x|, |y| ≤ 1e6; `w` 120–1200, `h` null or
    60–2000; `frame` an existing frame id or null. `frames`: `{"id"?, "title", "x", "y", "w", "h", "z"?}` upserted by
    id; without an id, a new one's id is `f-` + slug of its title (unique); an id that matches `^f-[a-z0-9-]{1,64}$`
    and doesn't exist yet creates the frame with that id (undo brings a deleted frame back this way); title squashed,
    at most 80 characters, default "Frame"; `w`, `h` ≥ 160. `remove_frames`: ids removed, their items' `frame` set to
    null.
  - `restore(board, names: list[str]) -> list[dict]` — the `.md` file names `delete` returned (their basenames) move
    back from `.trash/` with their files (`<stamp> <id> <file name>`, back to `files/<file name>`, made unique), under
    their old id or `-2` … when it was taken meanwhile; positions are not restored (the client sends them with
    `layout`); an unknown name → 404.
  - `add(…, frame=id)` places the item inside that frame (24 from its left, 56 from its top, below the lowest item
    already in it with 24 between) and grows the frame's height to hold it; `at` wins over `frame` for the position but
    `frame` is still stored; neither → the column rule of Task 1, written at once. A new item's `z` is the board's
    highest + 1.
  - `citable(board) -> list[dict]` — `{"key", "label", "title", "csl", "board", "id"}`, deduplicated by key (first
    wins), in the spec's order: the board's own citable items and its links' originals; then (book boards) the shared
    board's; then (book boards) the book's `sources.json` entries (`board`/`id` null). `label` is `short_label(csl)`:
    the Python twin of `BookText.sourceShort` (family names with particles; one: `van Dijk 1998`; two joined with ` & `;
    three or more `X et al.`; no author → the title cut to 32 characters with `…`; then the year).
  - Summaries of quotes gain `source_label` (`label` plus `, <locator>`), or the key when unresolved; summaries of
    citable items on a book's board gain `in_book` (their key is in that book's `sources.json`).
  - Links: `add(board, {"type": "link", "board": other, "item": id})` (400 when the original doesn't exist, or when
    `other` is this board); `read()`/`item()` of a link carry `link: {"board", "board_title", "item", "missing": bool}`
    and, when not missing, the original's summary fields (type, title, excerpt, text in `item()`) with `id` still the
    link's own; `update(board, link_id, fields)` updates the original (409s against the original's mtime).
  - `move(board, ids, to, link=False) -> list[dict]` — per the spec: link → new link items on `to` (an existing link to
    the same original is reused; linking a link links its original); move → the `.md` and its files to `to` (new id if
    taken; `files/` names made unique and the front matter updated), position dropped here and placed on `to` by the
    column rule, every link on every board that pointed at `(board, id)` rewritten to `(to, new id)`. Sources follow
    the spec's "Keeping a quote's source": a quote whose `source` key isn't in `citable(to)` gets a link on `to` to the
    item that holds the key on the old board, or — when the key came from the old book's `sources.json` — a `source`
    item on `to` made from that entry; a citable item moved off a board where quotes still cite its key leaves a link
    to it behind. Moving a link onto its original's board deletes the link and returns the original. `to == board` →
    400.
  - `search(q, board=None, every=False) -> list[dict]` — `{"board", "board_title", "id", "type", "title", "snippet"}`;
    case- and accent-insensitive (`unicodedata` NFKD fold) substring over title, body, tags, `url`, `site` and the
    csl's title, container title and names; `snippet` is 40 characters either side of the first match in the body
    (else the title), whitespace squashed, with `…` at cut ends; links are left out (their originals are found);
    `q` shorter than 2 characters → `[]`.
  - `use(book, board, id) -> dict` — per the spec's "Quotes into the text": the item (a link resolves to its original)
    is a quote → `{"kind": "quote", "paragraphs": [[inline nodes], …], "words": n, "key": key | None, "locator",
    "added": bool}` where `paragraphs` are the inline contents of `manuscript.parse(body)`'s paragraphs (other blocks
    flattened to one text node each) and `words` is `manuscript.counts(body)["words"]`; a source, clip or other item
    with `csl` but no image → `{"kind": "cite", "key", "added"}`; an image → `{"kind": "image", "src": <from
    Books.save_image(book, name, data)>, "alt": title}`; a note or piece → 400 "Notes and links to pieces don't go into
    the text." The key is resolved with `citable(board)` (the item's own board), then the `sources.json` of `book`
    (the book being written). A key found nowhere → `{"kind": "quote", …, "key": key, "added": False, "warning":
    "This quote's source isn't on its board any more."}` (cited by its key, nothing added). Adding to `sources.json`:
    per the spec (same source = same URL after lower-casing the host and dropping a trailing `/`, or same folded title
    and same first year); conflict → next free key (ends in a digit: `b`, `c` …; else `-2`, `-3` …), written with
    `Books.save_sources`.

**Interfaces:**
- Produces in `clip.py`: `UA = f"Mozilla/5.0 (compatible; Studio/{__version__})"`; `class ClipError(ResearchError)`;
  `Fetched` (a namedtuple `url, final_url, status, ctype, charset, data`); `public_only(ip) -> bool` (`ip.is_global` and
  not multicast; an IPv4-mapped IPv6 address is judged as its IPv4 address);
  `fetch(url, *, allow=public_only, timeout=20, limit=10_000_000, max_redirects=5) -> Fetched` — `http.client` with a
