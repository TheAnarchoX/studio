# Books, part 1 — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Books area in Studio where a book is written day to day: a shelf, book kinds, a calm ProseMirror
writing window with notes, citations, index terms and comments, history and editions, import from .docx and
Markdown, export to .docx and Markdown.

**Architecture:** Plain files under `<library>/Books/<Book>/` (`book.json`, one Markdown file per piece). One
Python module owns the Markdown dialect (`manuscript.py`: Markdown ⇄ ProseMirror JSON), one owns the files
(`books.py`), and import and export are their own modules. The browser never parses Markdown: it loads and saves
ProseMirror JSON. ProseMirror is vendored as one committed IIFE file (`window.PM`), so Studio still runs without
Node or a build.

**Tech Stack:** Python 3.11+, markdown-it-py + mdit-py-plugins, mammoth, python-docx, unittest; ProseMirror
(vendored with esbuild at development time only); plain JS/CSS.

**Spec:** `docs/superpowers/specs/2026-11-12-books-design.md` (part 1). **Requires** plan
`2026-11-12-updater-styles-home.md` to be done: route tables (`studio/routes.py`, `tests/support.py`), the styles
(`styles.py`, `palettePicker`, `fontPicker`), Home hooks (`home.SOURCES`, `window.homeSections`) and example hooks
(`examples.EXTRA`, `examples.EXTRA_REMOVE`).

## Global constraints

- **Principle:** Studio works equally well with AI as without and nobody has to touch a config file: everything in
  this plan is reachable from the interface, and part 4's Claude tools will only add to what the interface can do.
- Everything in plan A's global constraints applies (tests with `python -m unittest discover tests`, no front-end
  build at runtime, route tables for endpoints, atomic writes, nothing personal in the repo, interface copy rules,
  commit identity and trailer, no push).
- The Markdown dialect is exactly the spec's table; `manuscript.py` is its only implementation.
- Book folders: `<config.ART>/Books/<folder_name(title)>/`; deletes go to `Books/.trash/`.
- `book.json` keys unknown to Studio are kept on every write.
- A piece open in an editor is never overwritten under the cursor: saves carry the file's mtime and get a 409
  when the file changed since.
- New dependencies: `markdown-it-py>=3`, `mdit-py-plugins>=0.4`, `mammoth>=1.8`, `python-docx>=1.1`.

## Review focus

1. **Two windows or another program editing the same piece:** a stale save gets 409 and the editor offers
   *Reload* or *Keep mine*; nothing is lost silently. Pinned in Task 3 (`test_stale_save_is_refused`).
2. **Markdown edited by hand or by other tools:** `_italic_`, setext headings, reference-style footnotes
   (`[^1]` + `[^1]: …`), CRLF line endings, a BOM: all parse without loss and are saved back in the canonical
   form. Pinned in Task 1 (`test_non_canonical_input_normalises`).
3. **Pasting from Word, Google Docs or a web page:** italic and bold stay, headings map to `##`/`###`,
   everything else becomes plain paragraphs; no foreign styles. Pinned in Task 7 (browser check with three
   pastes).
4. **Big books:** a 30,000-word piece parses in under 2 s; search across 100 pieces of 3,000 words in under 2 s.
   Pinned in Tasks 1 and 2.
5. **Dutch and other non-English text:** „…” and “…”, ellipses, diacritics in titles and file names (`Één week`
   → `een-week.md`), Windows-reserved names (`Con` → `con-1.md`), word counts with apostrophes (`'s avonds` is one
   word). Pinned in Tasks 1 and 2.

### Task 1: The manuscript dialect

**Files:**
- Create: `studio/manuscript.py`, `tests/test_manuscript.py`
- Modify: `pyproject.toml` (add `markdown-it-py>=3`, `mdit-py-plugins>=0.4`)

**Interfaces:**
- Produces: `manuscript.SCHEMA = {"nodes": ["doc", "title", "heading", "paragraph", "blockquote", "scene_break",
  "epigraph", "attribution", "poem", "image", "page_break", "hard_break", "note", "cite", "text"], "marks": ["em",
  "strong", "idx", "comment", "smallcaps", "lang"]}`.
- Produces: `manuscript.parse(md: str, form: str = "prose") -> dict` and
  `manuscript.serialize(doc: dict, form: str = "prose") -> str` (ProseMirror JSON: `{"type": "doc", "attrs":
  {"form"}, "content": [...]}`; text nodes `{"type": "text", "text", "marks"?}`).
- Node attributes: `heading.level` 2–3; `poem.src` (string or null: a linked poem has `src` and no content);
  `image.src`, `image.alt`, `image.width` (string like `"60%"` or null); `note` is inline with content
  `inline*`; `cite.items = [{"key", "prefix", "locator"}]`; marks `idx.term` (string or null),
  `comment.note`, `lang.lang`.
- Produces: `manuscript.plain_text(doc) -> str` (body text, no notes, no comment notes, no citations),
  `manuscript.counts(md: str, form="prose") -> {"words": int, "note_words": int, "notes": int}`,
  `manuscript.title_of(md: str) -> str | None`.

Dialect rules beyond the spec table (canonical output):
- Blocks are separated by one blank line; the file ends with one newline; LF only.
- `blockquote` is `> ` per line (block quotations in prose).
- Inline: `*em*`, `**strong**`; span marks on the same range combine into one span:
  `[text]{.idx .smallcaps term="a > b" lang=en}`; attribute values are double-quoted with `\"` and `\\` escaped;
  a comment is `[text]{.comment note="…"}`.
- Notes: `^[…]` with the note's inline content serialized by the same rules (notes can't contain notes).
- Citations: `[@key]`, `[see @key, p. 12]`, `[@a; @b, pp. 3–5]` — items split on `;`; text before `@` is the
  prefix, text after `key, ` the locator.
- Hard break in prose: a backslash at the end of the line.
- Poem lines (inside `::: poem` and in a piece whose form is `poem`): one line per line, stanzas separated by a
  blank line, no backslashes; inline marks, notes and citations are allowed in lines.
- Epigraph: `::: epigraph`, its paragraphs, then the attribution as `— text`, then `:::`.
- Escaping: `\` before `*`, `_`, `[`, `]`, `` ` ``, and `\` itself; at line start also before `#`, `>`, `-`, `+`,
  `:::`, a number followed by `.`, and a line that is exactly `***`.
- Parsing uses markdown-it-py with `footnote_plugin` (inline and reference notes, both become `note` nodes),
  `attrs_plugin(spans=True)`, `colon_fence_plugin` (fence content is re-parsed for `epigraph`, read line by line for
  `poem`), and a custom inline rule for citations that runs before `link`.

**Files:**

**Interfaces:**

  epilogue, afterword, acknowledgements, appendix, about-author`), `AUTO` (`half-title, title-page, copyright, toc,
  notes, bibliography, index`), `FORMS` (`prose, poem, essay, letter`), `STATUSES` (`idea, draft, revised, final`).
- Produces: `books.BooksError(StoreError)`: `BooksError(message, code=400, extra=None)`; `.code` is 409 for

- Produces: `books.Books(root: Path)` with
  `list() -> list[dict]` (per book: id, title, author, kind, language, words, pieces, updated, by_status);
  `create(title, author="", language="en", kind="memoir", look=None) -> dict`;
  `read(book) -> dict` (book.json plus per entry `title`, `words`, `note_words`, `mtime`; `days` = words written per
  date, last 30 days); `update(book, fields) -> dict` (`details`, `title`, `subtitle`, `author`, `language`, `kind`,
  `features`, `contents`, `goals`, `look`, `palette`, `fonts`, `style`; `apply_kind_defaults: true` resets
  `features` to the kind's); `piece(book, file) -> dict` (`doc`, `md`, `title`, `kind`, `form`, `status`, `mtime`,
  counts, `linked` = `{src: {"title", "lines"} | {"missing": true}}` for linked poems);
  `save_piece(book, file, doc=None, md=None, base_mtime=None, leaving=False, force=False, now=None) -> dict`;
  `new_piece(book, kind, form="prose", title="", after: str | None = None) -> dict`;
  `delete_piece(book, file) -> Path`; `delete_book(book) -> Path`; `history(book, file) -> list[dict]`
  (`{"when", "words"}` newest first); `snapshot_text(book, file, when) -> str`;
  `restore(book, file, when) -> dict` (snapshots the current text first); `edition(book, name, now=None) -> Path`;
  `search(book, q, whole=False, case=False) -> list[dict]` (`{"file", "title", "index", "before", "match", "after"}`
  over each piece's plain text, 40 characters of context); `replace(book, q, repl, whole=False, case=False,
  file=None, index=None) -> {"replaced": int}` (rewrites through `parse`/`serialize`, so markup survives);
  `sources(book) -> list`; `save_sources(book, items) -> list`; `stamp() -> float`; `save_image(book, name, data)
  -> str` (returns `../images/<unique name>`).
- Rules: piece files are `slugify(title) or kind` + `.md`, made unique with `-2`, `-3`; Windows-reserved stems
  (`con, prn, aux, nul, com1–9, lpt1–9`) get `-1`. Snapshots go to `drafts/<file stem>/<YYYY-MM-DDTHHMM>.md` when
  `leaving` and the text differs from the newest snapshot, or when ≥ 30 minutes passed since the newest snapshot
  and the text differs; never for identical text. Every save adds the positive word delta to
  `Books/<b>/.studio/days.json` (`{"2026-11-12": 412}`). `save_piece` with `base_mtime` older than the file's mtime
  raises `BooksError(code=409)` unless `force`. Editions copy `book.json`, `manuscript/`, `images/`,
  `sources.json` and `cover/` (when present) to `editions/<YYYY-MM-DD> <name>/`. Sources are CSL-JSON: each item
  needs a unique `id` and a `type`; `title` recommended.

`KINDS` (features; starting `contents` after the three title-page autos and before the back-matter autos):

| Kind | notes / noteNumbering / sources / index / figures / contentNote | Starting pieces | Back autos |
|---|---|---|---|
| fiction | off / chapter / false / false / false / false | chapter "Chapter 1" | — |
| memoir | endnotes / chapter / false / false / false / false | dedication, toc, chapter "Chapter 1" | notes |
| nonfiction | endnotes / chapter / true / true / false / false | toc, introduction, chapter "Chapter 1" | notes, bibliography, index |
| academic | footnotes / book / true / true / true / false | toc, introduction, chapter "Chapter 1", appendix | notes, bibliography, index |
| poetry | off / chapter / false / "first-lines" / false / false | toc, chapter "Untitled" (form poem) | index |
| essays | endnotes / chapter / false / false / false / false | toc, chapter "Essay 1" (form essay) | notes |

  `book_import.html_to_blocks(html: str) -> list[dict]` (blocks `{"type": "h1"|"h2"|"h3"|"p"|"quote"|"title"|"subtitle",

- Mammoth style map: `p[style-name='Title'] => h1.doc-title:fresh`, `p[style-name='Subtitle'] => p.doc-subtitle:fresh`,

- Rules, in order: (1) the Title style, or the first heading before any body text, is the title; an all-caps title
  is title-cased (`TEST BOOK` → `Test Book`), the review screen shows it editable; (2) a Subtitle or `h2` right after
  it is the author when it equals the signature (case-insensitive), else the subtitle; (3) empty headings and empty
  paragraphs are dropped; (4) a body paragraph of ≤ 40 words, entirely italic, before the first piece heading
  becomes a `dedication` piece; (5) each remaining `h1` starts a piece; its kind comes from `HEADING_KINDS`

  acknowledgements, opdracht/dedication → dedication, bijlage/appendix → appendix, over de auteur/about the author →
  about-author`, case-insensitive), else `chapter`; (6) at the start of a piece, one to four quote-like paragraphs
  (italic-only, a blockquote, or starting with a quote mark) followed by a paragraph that starts with `-`, `–` or
  `—` after whitespace become an `epigraph` with that line as its attribution (`— ` + the text, outer italics and
