# Books, part 4 — Claude's tools: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MCP tools that let Claude read a book, keep its sources and propose edits, notes, index terms, citations
and comments, which wait in a calm Suggestions panel in the writing window until the author accepts or rejects them;
then thin wrappers over part 2's composer and part 3's research board.

**Architecture:** One shared service, `studio/suggestions.py` (the file `Books/<Book>/suggestions.json`, finding
the quoted words again, applying a suggestion to a piece's ProseMirror JSON), called both by the app's routes and by
the MCP tools, as `making.py` is for carousels. The book tools register on the existing `MCPServer("studio")` from a
new `studio/mcp_books.py`. Accepting goes through part 1's guarded path (`BookTools.guarded`): open pieces are saved
and locked, the server applies and writes (with a snapshot), the pieces are read again as one undo step. The panel and
the in-text preview live in a new `studio/static/book-suggest.js`, mounted by the rail.

**Tech Stack:** Python 3.11+ stdlib, the MCP SDK already in use (`mcp.server.mcpserver`), unittest; plain JS with the
vendored ProseMirror; node for the JS helper tests.

**Spec:** `docs/superpowers/specs/2026-11-13-books-part-4-design.md` (part 4), on top of
`docs/superpowers/specs/2026-11-12-books-design.md` and `docs/superpowers/plans/2026-11-12-books-part-1.md`.

## Global Constraints

- Studio works equally well with AI as without, and nobody touches a config file (connecting Claude excepted).
- No MCP tool writes a file under `manuscript/`, `book.json`, a piece's status or the order of the book.
- Typing is never lost; an open piece is never overwritten under the cursor (changes on disk go through `guarded`).
- Files are the database: atomic writes (`store.write_text`); unknown keys kept; a file that can't be read is never
  written over.
- Every view escapes user text (`esc()`); a text column is never narrower than 360 px.
- Interface copy: plain, sentence case, no badges or flourishes.
- Nothing personal in the repo: no real names, poem or book titles, personal paths or emails. Test books use made-up
  titles ("Harbour-Lights", "The Pier").
- Tests: `.venv\Scripts\python.exe -m unittest discover tests` from the worktree (the main checkout's venv;
  `python -m` puts the worktree first on `sys.path`), and `tests/e2e_mcp.py`. 380 tests pass at the start.
- Commits as the repo-local `TheAnarchoX <theanarchox@proton.me>`, message ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; commit normally (signing works through the SSH agent);
  never pass options that skip signing or hooks; if signing fails, stop and report it. No push, tag, release or merge
  into `main`.
- Scratch servers: temp `STUDIO_CONFIG`/`STUDIO_ART`/`STUDIO_CACHE`, ports 4748–4766; never port 4747, never
  the author's library folder, never `%APPDATA%\Studio\config.json`. Stop every process you start.
- Constants (spec): context 32 characters each side; quote 1–1000 characters; index term ≤ 200 characters; 200 items
  per `suggest` call; 1000 open suggestions per book; the newest 1000 decided kept; 500 entries in `read_book`'s
  lists; 50 decided rows in the panel; lock retried 5 s, broken after 30 s.

## Review Focus

1. **The author types in a piece while Claude's suggestion for it is accepted from the panel:** the typing is saved
   first and survives; the accepted change lands after it; Ctrl+Z takes back only the accepted change. Pinned in
   Task 10 (browser check, step "accept while typing").
2. **The same short phrase occurs several times in a piece** ("en toen", "he said"): the suggestion lands on the
   occurrence Claude meant, by its context, in Python and in the browser alike. Pinned in Tasks 2 and 9
   (`test_locate_picks_by_context`, the shared fixture).
3. **The app and Claude write `suggestions.json` or `sources.json` at the same moment:** neither write is lost.
   Pinned in Task 1 (`test_lock_across_processes`).
4. **Hand-edited or damaged `suggestions.json`** (not JSON, a list instead of an object, unknown keys, a suggestion
   missing fields): unreadable is never written over and is said; unknown keys survive; a malformed entry is
   skipped in listings and kept in the file. Pinned in Task 1 (`test_unreadable_file_is_kept`,
   `test_malformed_entries_are_kept_and_skipped`).
5. **Dutch text and typography in quotes:** curly quotes „…”, ’t, ellipses, diacritics and non-breaking spaces in the
   quoted words match exactly as written; the panel shows them unchanged and escaped. Pinned in Task 2
   (`test_locate_dutch_typography`) and Task 9 (`row escapes and keeps typography`).

### Task 2: Finding the words again, and applying a suggestion

**Files:**
- Modify: `studio/suggestions.py`, `tests/test_suggestions.py`
- Create: `tests/fixtures/suggest-locate.json` (shared with Task 9)

**Interfaces:**
- Consumes: `books._containers`, `books._matches`, `books._pattern`, `books._rewrite`, `books.GAP`,
  `manuscript.SCHEMA`.
- Produces: `matches(doc: dict, quote: str) -> list[tuple]` = `books._matches(doc, books._pattern(quote, False,
  True))` (every container, captions included: the numbering Find uses).
- Produces: `score(text: str, start: int, end: int, before: str, after: str) -> int` = length of the common suffix of
  `text[:start]` and `before` + length of the common prefix of `text[end:]` and `after`.
- Produces: `locate(doc: dict, s: dict) -> dict | None` → `{"kind": "text"|"note", "box": <inline list>, "start",
  "end", "index", "text"}`. Candidates: matches whose container kind equals `s.get("in", "text")`. One candidate →
  it. Several → the highest `score` (first on a tie); when `s["before"] + s["after"]` is not empty and the best
  score is 0 → None. None → None. `index` is the match's number in `matches(doc, quote)`.
- Produces: `context(text: str, start: int, end: int) -> tuple[str, str]` = `(text[max(0, start - CONTEXT):start],
  text[end:end + CONTEXT])`.
- Produces: `apply(doc: dict, s: dict, sources: list) -> bool` — changes `doc` in place; False (doc untouched) when
  `locate` is None or a cite's `source` isn't an `id` in `sources`.
  - `edit`: `books._rewrite(box, kind, [(start, end)], s["text"])`.
  - `index` / `comment`: split the text nodes at `start` and `end` (a helper `_split(box, offset) -> int` returning
    the node index where `offset` begins), then on each text node in between set the mark: `{"type": "idx",
    "attrs": {"term": term}}` where `term` is None when `s.get("term")` is empty or equals the quote; `{"type":
    "comment", "attrs": {"note": text}}`, an existing comment's note joined as `old + " · " + new`; an existing idx
    mark is replaced. Marks sorted by `manuscript.SCHEMA["marks"]` order.
  - `note`: insert `{"type": "note", "content": [{"type": "text", "text": s["text"]}]}` at `end`.
  - `cite`: insert `{"type": "cite", "attrs": {"items": [{"key": s["source"], "prefix": "", "locator":
    s.get("locator", "")}]}}` at `end`.
- Fixture shape (`tests/fixtures/suggest-locate.json`): `[{"name", "md", "form", "s": {"quote", "before", "after",
  "in"}, "want": null | {"index", "start", "end", "kind"}}]`, at least 8 cases: unique; repeated with `before`;
  repeated with `after`; repeated with context matching neither (null); repeated, empty context (first); in a note;
  across a note number (null); a poem line, Dutch typography („…”, ’t, …, a no-break space).

  - `test_apply_index_term_and_mark_order`: index on a word that is italic → `[*word*]{.idx term="t"}` round-trips;

  - `test_apply_comment_joins_existing`: words already commented `"a"`, a comment suggestion `"b"` → note `"a · b"`.
  - `test_apply_note_and_cite_after_the_words`: `"the harbour."` with a note after `"harbour."` → `the
